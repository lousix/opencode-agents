【opencode-agents】【H-01】Plugin tools lack session ownership verification — cross-session IDOR and data manipulation High

漏洞名称Plugin tools lack session ownership verification — cross-session IDOR and data manipulation
严重程度High
CVSS8.1
CWECWE-863
置信度已验证
漏洞类型IDOR
复核结论VERIFIED / CONDITIONAL_SOURCE / KEEP
位置.opencode/plugin/audit-db.js:248
发现Agentaudit-d2d3d9-control

一、漏洞描述

All 16 plugin tools in audit-db.js operate on a shared database (~/.opencode/audit.db) without any session ownership or authorization checks. Any caller can: (1) insert findings into any session, (2) update/modify findings across sessions, (3) prematurely complete any session, (4) reference findings from other sessions in attack chains, (5) generate reports for any session. This enables cross-session data manipulation and IDOR.

二、漏洞根因

攻击者可控输入从 .opencode/plugin/audit-db.js:8 进入系统，经业务转换后到达 .opencode/plugin/audit-db.js:709。链路中未记录有效净化、参数化、白名单或权限拦截。 根因是外部输入在到达危险操作前缺少有效安全边界控制，导致 IDOR 可被触发。

三、攻击者利用方法

In serve mode: 1. Connect to port 4096 (no auth per F1334) 2. Call audit_save_finding(session_id=victim_session, title="Fake Critical", severity="Critical") → inject false finding 3. Call audit_update_finding_after_verification(finding_id=victim_finding, severity="Info") → downgrade real finding 4. Call audit_complete_session(session_id=victim_session) → prematurely close victim session
